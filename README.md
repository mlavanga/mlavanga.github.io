# mlavanga.github.io

Personal academic/professional website of **Mario Lavanga** — Senior Research Engineer &
Project Leader working on Health AI, causal inference and biosignal processing.

- Live site: https://mlavanga.github.io
- LinkedIn: https://www.linkedin.com/in/mario-lavanga-87a0a7a3

## Stack

- **Next.js 16** (App Router) with **static export** (`output: 'export'`) — no backend, no API
  routes, fully static.
- **TypeScript** + **Tailwind CSS 4**.
- Deployed to **GitHub Pages** via GitHub Actions.
- Two interactive, client-side ML demos that run entirely in the browser (no server):
  - **Health-AI Lab** (`/health-lab/`) — a 1-D CNN classifying 12-lead ECGs into the five
    PTB-XL diagnostic superclasses, via ONNX Runtime Web.
    Model source: [github.com/mlavanga/ecg-ptbxl](https://github.com/mlavanga/ecg-ptbxl).
  - **ADME Lab** (`/adme-lab/`) — a 13-endpoint ADMET panel predicted from a SMILES string
    with conformal uncertainty and applicability-domain flags, via RDKit-JS + ONNX Runtime Web.
    Model source: [github.com/mlavanga/adme-lab](https://github.com/mlavanga/adme-lab).

## Getting started

```bash
npm install
npm run dev      # dev server on http://localhost:3000
npm run build    # static export → ./out
npm run lint     # eslint (flat config in eslint.config.mjs)
```

There is no test suite; verification is done by building and inspecting the rendered output.

## Architecture

The homepage is **data-driven from a single file**: [`app/data/content.ts`](app/data/content.ts)
exports typed arrays (`personalInfo`, `experience`, `education`, `projects`, `publications`,
`skills`, `media`) that [`app/page.tsx`](app/page.tsx) lays out via presentational components in
[`app/components/`](app/components/). **To change site content, edit `content.ts`**, not the
components.

- SEO / metadata and the JSON-LD `Person` schema live in [`app/layout.tsx`](app/layout.tsx).
- `sitemap.xml` and `robots.txt` are generated by [`app/sitemap.ts`](app/sitemap.ts) and
  [`app/robots.ts`](app/robots.ts).
- The two lab pages are [`app/health-lab/`](app/health-lab/) and [`app/adme-lab/`](app/adme-lab/);
  their browser-only components use `next/dynamic` with `ssr: false` and load ML models/assets
  from `public/`.

## Deployment

Pushing to `main` (or `master`) triggers
[`.github/workflows/nextjs.yml`](.github/workflows/nextjs.yml): it runs `next build` and
publishes `./out` to GitHub Pages. The workflow uses `actions/configure-pages` with
`static_site_generator: next` to auto-inject `basePath`.
